# АгроМаркет (React)

Запуск (два терминала):

    npm install
    npm run dev        # приложение на http://localhost:5173

Данные отдаёт собственный сервер **agromarket-server** (http://localhost:3000, `npm run dev`
в его папке). json-server (`npm run server`) больше не нужен.

## Лабораторная 3
ProductCard (props), useState, useEffect + fetch, поиск (controlled input),
счётчик корзины (lifting state up), бонус: loading/error.

## Лабораторная 4 — вёрстка

### Box model карточки (часть 1)
Значения для карточки из старых стилей (лаб. 2: `.card { width: 220px; padding: 12px; }`),
проверьте их в DevTools → Computed:
- content: 220px, padding: 12px, border: 0, margin: 0
- итоговая ширина на экране без `border-box`: 220 + 2·12 = **244px**
- с `box-sizing: border-box` ширина стала **220px** (padding входит в width)
- в дереве было много вложенных `<div>`, по которым нельзя понять, где шапка, каталог и подвал
  (семантических тегов не было).

### repeat(4, 1fr) на узком экране (часть 4)
Колонок всегда 4, поэтому при ~500px каждая карточка сжимается до ~100px:
текст переносится по буквам/слипается, кнопки и цены не помещаются, страница выглядит сломанной.

### auto-fit vs auto-fill (часть 4)
`auto-fit` схлопывает пустые колонки, и 1–2 найденные карточки растягиваются на всю ширину ряда;
`auto-fill` оставляет пустые колонки, поэтому карточки сохраняют обычную ширину и справа остаётся
пустое место. Выбран вариант: **auto-fit** (замените, если вам больше нравится auto-fill).

### Адаптивность (часть 5)
Значения получены расчётом по CSS — перепроверьте в DevTools на 375 / 768 / 1280 px.

| Ширина | Колонок | Где «Доставка» | Шапка |
|--------|---------|----------------|-------|
| 375    | 1       | под каталогом  | столбик |
| 768    | 3       | под каталогом  | ряд |
| 1280   | 3       | справа от каталога | ряд |

### Бонус
- липкая шапка (от 768px) и липкая боковая панель «Доставка» (от 1024px).

Скриншоты на 375 и 1280 px — в папке `screenshots/`.

## Лабораторная 5
Каталог и форма заявки работают через Express API (`http://localhost:3000/api`):
GET /products, POST /orders. Поле объёма в форме теперь `name="quantity"`,
кнопка показывает «Отправка…» пока идёт запрос.

## Лабораторная 6
Данные теперь хранит PostgreSQL (agromarket-server). Frontend почти не менялся:
каталог запрашивает `?limit=100`, в форме заявки добавлен выбор товара (`product_id`),
для товаров без картинки показывается заглушка.
